# Student Registration Streamlit App 🚀

My first Streamlit web application built using Python.

## 📌 Project Overview

This is a simple student registration form created with Streamlit.  
Users can enter their details and submit the registration form.

## ✨ Features

- Student Name Input
- Age Selection
- Branch Selection
- Gender Selection
- Hobby Selection
- Submit Button
- Display Student Details

## 🛠️ Technologies Used

- Python
- Streamlit

## ▶️ How to Run

Install Streamlit:

pip install streamlit

Run the application:

streamlit run app.py
